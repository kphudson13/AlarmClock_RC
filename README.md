# Remote Alarm Clock Build
Code and related files for a remote controlled alarm clock based on an UNO R3. 
## Remote Control
| Button | Function |
|---|---|
| **PWR** | Turns the LCD backlight on or off, also stops the alarm when sounding. |
| **STOP** | Cancels the currently scheduled alarm, also stops the alarm when sounding. |
| **PLAY** | Enters **Alarm Setting** mode, also stops the alarm when sounding. |
| **EQ** | Enters **Time Setting** mode. |
| **REPT** | Enters **Song choice** mode. |
| **BACK/FWD** | Scroll songs in **Song choice** mode. **BACK** is also backspace |
| **0–9** | Used to enter the time or alarm in `HHMM` format. |
| **UP/DOWN** | Control the LCD contrast. |
